  <b>Experimental PlayStation 4 emulation project for ARM64 Android devices.</b>

## 📱 О проекте NEOS4

**NEOS4** — экспериментальный проект эмуляции PlayStation 4, ориентированный
на ARM64-устройства под Android.

Проект основан на бинарных сборках **Bachata S4** / **Bachata S4+** и содержит
независимые модификации, исследования совместимости, работу с runtime,
улучшения контроллеров, изменения Android UI и исправления для отдельных игр.

Историческая база — **Bachata S4 0.1.8** и последующие сборки Bachata S4+.

Полный исходный код приложения, соответствующий APK, в публичном виде не
был доступен. Поэтому NEOS4 следует понимать как независимое community-
модификацию и исследовательский проект, а не как традиционный форк исходников.

## 🚀 Текущий релиз

### NEOS4 (на базе Bachata S4+)

Основные цели проекта:

- Эмуляция PS4 на ARM64 Android
- Бэкенд FEX
- Экспериментальный бэкенд Box64
- Настройки на игру
- Поддержка физических контроллеров
- Сенсорное управление
- Улучшения UX, ориентированные на контроллер
- Работа с Vulkan
- Исследования синхронизации GPU
- Улучшения совместимости памяти
- Исправления под конкретные игры
- Диагностические инструменты
- Тестирование на реальном железе

➡️ Сборки публикуются в разделе **Releases**.
